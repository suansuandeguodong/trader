# EMA20 拐头反转 · 量化实盘交易

把 `ema20_reversal` 监控程序的信号逻辑升级为「信号 → 自动下单 → 自动止盈止损」的
实盘交易机器，多空双向，币安 USDT 永续合约。

## 目录结构

| 文件 | 说明 |
|------|------|
| `market.py` | 数据获取（复用自监控程序，走本地代理） |
| `sliding.py` | 滑动窗口 + EMA20 增量更新（复用） |
| `reversal.py` | 向上拐头状态机（复用） |
| `reversal_down.py` | 向下拐头状态机（复用） |
| `broker.py` | **新增**：币安合约下单/平仓/撤单/查询/精度对齐 |
| `risk.py` | **新增**：出入场规则、盈亏比、仓位计算、状态管理 |
| `trader.py` | **新增**：主循环编排（信号撮合 + 下单 + 持仓管理） |
| `trade_log.py` | **新增**：交易历史落盘（JSONL 追加写入，供复盘） |
| `config.yaml` | 交易参数 |
| `.env` | API 密钥（不入库） |

## 交易规则

- **开仓**：15m K 线收盘前 15 秒识别拐头信号（向上做多 / 向下做空），
  以信号 K 线收盘价挂限价单。
- **止损** = 信号 K 线开盘价。
- **止盈** = 入场价 ± 止损幅度的一半（盈亏比 2:1，亏 2 赚 1）。
- **撤单**：挂单后 15 分钟未成交则撤销。
- **仓位**：每笔 108 USDT 名义值，杠杆 10x，最大同时持仓 15 个。
- **做多风控**：同一根 K 线同时触发做多信号 ≥ 6 个时，本轮所有做多信号都不做
  （防诱多团灭），做空不受影响。
- **重复信号**：持仓/挂单期间的重发信号跳过（按「币 + 方向」区分，同币多空可并存）。
- **部分成交保护**：限价单部分成交时，每新成交一部分就立即补挂对应数量的止损止盈，
  不留无保护的裸仓；剩余未成交部分继续等待，15 分钟超时撤单。
- **连续止损冷静期**：连续 3 笔平仓全为止损（中间夹盈利/止盈单则重新计）时，进入
  2.5 小时冷静期，冷静期内不再开新仓；冷静期从**第 3 笔止损平仓发生的时刻**起算。

## 交易历史记录（复盘）

程序运行时会把每笔交易的完整生命周期**实时追加**到项目根目录的
`trade_history.jsonl`（JSONL，每行一个事件），供后续复盘，无需再拉币安 API。

记录的事件类型及关键字段：

| 事件 | 说明 | 关键字段 |
|------|------|----------|
| `SIGNAL` | 信号触发（即使被过滤也记录） | K线时间/OHLCV、EMA、连续不涨根数、实体幅度、EMA历史 |
| `OPEN` | 开仓下单 | entry/stop/tp 三价、qty、名义值、orderId、信号上下文 |
| `FILL` | 成交（含部分成交增量） | 本次成交量、均价、累计成交量、总量、orderId |
| `STOP_TP` | 挂止损止盈 | 止损/止盈价、数量、两个 orderId |
| `CLOSE` | 平仓 | 原因、价格、持仓时长 |
| `POSITION` | 持仓补充信息 | 持仓时长、entry/stop/tp |
| `CANCEL` / `REJECT` / `ERROR` | 撤单 / 下单被拒 / 异常 | 原因 |

每条记录含公共字段 `event` / `ts` / `ts_iso` / `symbol` / `direction` / `trade_id`。
用 `trade_id` 可聚合出同一笔交易的完整链路（开仓 → 成交 → 挂单 → 平仓）。

> 注意：`trade_history.jsonl` 记录的是程序视角的事件流，平仓的精确已实现盈亏
> 仍需用币安成交记录（realizedPnl）校准。

## 运行

```bash
pip install requests pyyaml python-dotenv
python trader.py
```

## 重要提醒

1. **密钥安全**：`.env` 存真实密钥，务必不要提交到 git 或分享。
   曾暴露的密钥请去币安后台轮换。
2. **小资金起步**：程序默认每笔 108U，杠杆 10x（单笔占用保证金约 10.8U），请确认账户余额充足前谨慎调整参数。
3. **实盘风险**：加密货币合约为高风险杠杆交易，策略无回测验证，
   请自行评估风险，先用极小仓位观察。
